# GitHub Upload Steps

1. Download and extract the ZIP.
2. Create a GitHub repository named `craftroots-lab5-product-insights`.
3. Upload all files inside this folder.
4. Make sure `index.html` is directly in the root of the repository.
5. Go to Settings → Pages.
6. Choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
7. Save.
8. Wait for the live URL.

The live dashboard should open at:
`https://your-username.github.io/craftroots-lab5-product-insights/`

# Lab 5 Submission Note

## Project
CraftRoots Product Insights

## What I built
I built a product analytics prototype for CraftRoots using the Lab 5 toolkit idea:
- PostHog for event tracking
- Looker / Looker Studio for analytics dashboarding
- Dify for AI-assisted product insight summaries

## What the prototype shows
- A visible product insights dashboard
- A PostHog event tracking plan
- Sample analytics data
- Excel product dashboard
- Looker dashboard specification
- Dify prompts for weekly product insights
- Metric misinterpretation checklist

## Why this matters
CraftRoots should not make decisions only from traffic or vanity metrics. The dashboard uses Monthly Active Bookings — completed sessions — as the North Star because real value is created when travelers complete the craft workshop and artisans earn from the session.

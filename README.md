# CraftRoots Lab 5 — Product Insights

This package contains a complete Lab 5 submission for CraftRoots.

## Main files
- `index.html` — GitHub Pages product insights dashboard
- `style.css` — dashboard styling
- `dashboard.js` — demo metrics and visual funnel
- `CraftRoots_Lab5_Product_Insights_Dashboard.xlsx` — Excel analytics dashboard
- `PRODUCT_INSIGHTS_REPORT.md` — main report
- `LAB5_SUBMISSION_NOTE.md` — short teacher-facing note

## Folders
- `data/` — sample events, bookings, funnel metrics, event plan
- `posthog/` — PostHog setup and event tracking snippet
- `looker/` — Looker dashboard specification
- `dify/` — Dify product insight prompts
- `evaluation/` — metric misinterpretation checklist and test questions

## GitHub Pages upload
Upload all files in this folder to a GitHub repository. Then enable GitHub Pages:
Settings → Pages → Deploy from branch → main → root.

The dashboard will open at:
`https://your-username.github.io/your-repo-name/`

# Weekly Insight Report Prompt

Use the latest CraftRoots event and booking data to generate a weekly product insight report.

Include:
- North Star Metric movement
- Funnel drop-off
- Top city and craft
- Quality signals from ratings/reviews
- Artisan or operations issue
- One recommended experiment
- One warning about metric misinterpretation

Do not recommend product changes unless the metric has enough sample size and is compared by segment.

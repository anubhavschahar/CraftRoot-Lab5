# Metric Misinterpretation Checklist

Use this checklist before presenting product insights.

## Funnel metrics
- [ ] Did we separate page views from unique users?
- [ ] Did we compare booking-start to payment-success before blaming checkout?
- [ ] Did we use completed bookings instead of only payment success?
- [ ] Did we segment by city, craft, and acquisition source?

## Quality metrics
- [ ] Did we compare rating with review submission rate?
- [ ] Did we check whether low ratings are concentrated in one artisan/city?
- [ ] Did we check no-show and cancellation data?

## Growth metrics
- [ ] Did we avoid calling traffic growth product success?
- [ ] Did we check whether high traffic sources convert?
- [ ] Did we check CAC or ad spend before scaling a channel?

## Dify/AI output
- [ ] Did the AI cite which data columns it used?
- [ ] Did it avoid inventing live availability or live demand?
- [ ] Did a human validate the recommended action?
